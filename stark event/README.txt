# ⚡ STARK EVENTS — Campus Missions

**A creative college club events website inspired by Iron Man and Stark Industries.**

STARK EVENTS is a front-end web development project designed to help students discover upcoming college events and register for activities through a simple, interactive interface.

The website combines a futuristic Iron Man-inspired theme with a clean layout, glowing reactor visuals, and mission-based event cards to create a unique campus experience.

## 🚀 Features

- **Home Page:** A themed landing page introducing the STARK EVENTS initiative.
- **Upcoming Events:** Displays three sample college events using individual event cards.
- **Mission Details:** Clicking the event button opens a popup containing the event's date, description, and location.
- **Registration Form:** Allows students to enter their name and college email address for a selected event.
- **Interactive Interface:** Uses JavaScript to display event details and select the relevant event in the registration form.
- **Responsive Design:** Designed to adapt to different screen sizes through CSS.
- **Custom Visual Theme:** Features a dark background, red and gold accents, and an arc reactor-inspired illustration.

## 🛠️ Technologies Used

 Technology  Purpose 

 HTML5  Creates the structure and content of the website. 
 CSS3  Controls colors, layouts, styling, and animations. 
 JavaScript  Adds event interactions and registration form behavior. 
 SVG  Provides lightweight illustrations for the visual theme. 

## 💻 How to Run the Project

1. Download or clone the project to your computer.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, `app.js`, and the `images` folder are in the correct locations.
4. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code to preview the website while making changes.

No framework or package installation is required for this front-end project.

## ⚙️ How It Works

### 1. HTML — Website Structure

The `index.html` file contains the navigation bar, home section, event cards, about section, and registration dialog.

Each event has a button that identifies the selected event using a custom HTML data attribute.

### 2. CSS — Website Design

The `style.css` file controls the visual appearance of the website, including the Iron Man-inspired colors, event card layouts, typography, spacing, and responsive styling.

### 3. JavaScript — Interactivity

The `app.js` file contains a list of event details and adds click functionality to the event buttons.

When a student selects an event, JavaScript displays its details in a dialog and fills in the corresponding event name in the registration form.

The registration form also contains basic checks for required fields.

## 🎨 Design Inspiration

The design takes inspiration from the futuristic technology and visual identity associated with Iron Man and Stark Industries.

- **Dark backgrounds:** Create a cinematic, technology-inspired atmosphere.
- **Red accents:** Highlight important buttons and interactive elements.
- **Gold accents:** Add contrast and a premium feel.
- **Arc reactor illustration:** Acts as the central visual identity of the website.
- **Mission-based wording:** Makes exploring college events feel more engaging.

The goal is to make a simple college club website feel distinctive without relying on complicated frameworks or unnecessary features.

## ⚠️ Current Limitations

This project is a front-end prototype. It does not currently include a backend or database, so student registrations are not saved to a central system or sent to the club organisers.

The listed events are sample content and can be replaced with actual college event information.
